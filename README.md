# DIARIO
App web que sirve como diario y calendario cuyo diferenciador es el uso de imágenes y registrador de estado de ánimo, el resultado que va a dar una línea del tiempo con lo que se escribió, las fotos que se subieron y estados de ánimo para llevar un registro lineal de lo que se registró. 
Cuenta con una página de inicio que incluye el redireccionamiento al calendario, y línea del tiempo que solo muestran los meses y días en los que se registró algo y los registros por fechas respectivamente.
De igual manera cuenta con botones de acceso al diario para empezar a escribir una entrada y ver las entradas anteriores, así como editarlas y el botón de fotos donde puede ver las fotos que se han subido en orden de la semana y de igual manera subir una nueva o borrar las anteriores
